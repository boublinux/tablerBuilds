# Tabler Builds (`tablerBuilds`)

Welcome to the **tablerBuilds** repository. This repository hosts pre-compiled distribution builds, assets, and artifacts generated from the official [Tabler](https://github.com/tabler/tabler) open-source dashboard template.

---

## 📌 Overview

The main purpose of this repository is to store ready-to-use production builds (CSS, JS, fonts, images, and static HTML files) to easily integrate Tabler into projects without requiring a local Node.js or Sass build pipeline.
